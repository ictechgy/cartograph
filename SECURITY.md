# Security reporting

Include the tool version, platform, a minimal synthetic reproduction and the expected impact. Remove credentials and private customer data.

If this repository enables Security -> Report a vulnerability, use that private channel. Otherwise arrange private delivery through a contact method listed on the [maintainer profile](https://github.com/ictechgy). Do not put sensitive reproduction material in a public issue before coordinating disclosure.

Supported fixes depend on a confirmed reproduction and current source. No response deadline or support for every historical release is promised.
